3dv1 setup
what we build NOW so blobs slot in later
v1 groundwork checklist
· 1f drop-zones already treat proximity as meaning — blob-spawn reuses the same hit-testing, so keep cluster detection generic (n nodes, not just person→halo)
· node drag physics (elastic links, re-settle at speed 7) unchanged — blobs are just a new drop target type
· reserve the solid-ring style: v1 halos stay dashed so "solid ring = enterable room" reads unambiguously in v2
· artifact squares (1f-5) get a parent-meeting pointer now, so breakout notes can re-attach later
· graph canvas keeps empty space navigable — blobs need parking room; don't auto-center/crop the layout
